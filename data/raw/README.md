# Fuentes originales

Coloca aqui los archivos originales de cada fase de la encuesta:

- `.csv`
- `.xls`
- `.xlsx`

El nombre del archivo se usara como etiqueta de fase. Por ejemplo:

- `fase-1.csv`
- `fase-2.xlsx`
- `encuesta-final.xlsx`

Si esta carpeta esta vacia, el dashboard usa automaticamente `../cleanData.csv` como primera fase de datos.
